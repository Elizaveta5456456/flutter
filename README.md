# Lotus

Flutter-приложение — каталог бьюти-товаров.

## База данных / источник данных

Товары загружаются из публичного API **Makeup API**:

- URL: `http://makeup-api.herokuapp.com/api/v1/products.json`
- При старте приложения весь каталог прогревается в **оперативную память** (`ProductCache`)
- Дополнительно сохраняется локальный кэш в **SharedPreferences** (на устройстве), чтобы следующий запуск был быстрее и работал при нестабильной сети
- Профиль, избранное и корзина хранятся локально через **SharedPreferences**

Отдельной SQL/NoSQL базы (SQLite, Firebase и т.п.) в проекте нет.

## Запуск

```bash
flutter pub get
flutter run
```

## Структура

- `lib/screens` — экраны (поиск, каталог, профиль, товар, избранное, корзина)
- `lib/services` — API, кэш товаров, корзина, избранное, профиль
- `lib/widgets` — UI-компоненты
- `assets` — иконки, шрифт Inter, изображения
